# NovaCart – Full Stack Lab Project

NovaCart is an e-commerce website project developed as part of the Full Stack Lab. It provides a user-friendly interface for browsing products, viewing product details, managing a shopping cart, and proceeding to checkout.

## 🚀 Features

- **Home Page:** Main landing page of the website.
- **Products Page:** Browse available products.
- **Product Details:** View individual product information.
- **Shopping Cart:** Access the cart and review selected items.
- **Checkout Page:** Access the checkout interface.
- **Responsive Design:** CSS styling for a clean user interface.
- **Interactive Elements:** JavaScript for website interactions.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Interactive functionality.
- **React** – Component-based user interface.
- **Vite** – Development server and build tool.
- **Node.js and npm** – JavaScript development environment and package management.

## ⚙️ Installation and Setup

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/krishna-0094/full-stack.git
   ```

2. Open the project folder:

   ```bash
   cd full-stack
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal in your browser.
